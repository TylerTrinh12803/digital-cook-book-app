Put the cookbook on your desktop

  • Chrome or Edge (Windows / Mac): click the install icon at the right end of the address bar (a monitor with a ⬇ arrow), or the ⋮ menu → Cast, save and share → Install page as app / Apps → Install this site as an app.
  • Safari (Mac): File → Add to Dock.
  • iPhone / iPad: tap Share → Add to Home Screen.
  • Android: tap ⋮ → Add to Home screen.

The installed app opens in its own window, works without internet, and gets new recipes automatically.

Using another browser? Download the cookbook (.zip), unzip it, and double-click cookbook/index.html.
